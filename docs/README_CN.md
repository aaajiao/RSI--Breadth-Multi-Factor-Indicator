# RSI+ Breadth Multi-Factor Indicator v7.6 中文文档

[English README](../README.md) | 中文

RSI+ 是一个面向美股指数市场的 Pine Script v6 择时指标。当前脚本主要围绕 **SPY**、**QQQ**、**IWM**，把 **RSI**、**市场广度**、**成交量广度**、**背离**、**趋势过滤** 和 **多市场共振** 组合成一套统一决策框架。

---

## 概述

当前 `RSI+` 脚本包含这些模块：

- **核心评分引擎**：RSI + 市场广度 + 成交量广度
- **日线广度模式**：使用 `TW / FI`
- **日内广度模式**：使用 `ADD` 取代日线 `TW / FI` 评分块
- **自适应阈值系统**：自动回溯、波动率驱动、自适应 RSI 区间
- **信号质量过滤**：启用后仅允许 `A/B` 级信号通过
- **回撤加分**：5% / 10% / 20% 回撤分别加 `+1 / +2 / +3`
- **背离系统**：价格与 RSI 的多空背离，带冷却期
- **趋势过滤**：上升趋势中把卖出侧信号转为 `ELEVATED`
- **多市场共振**：检测 SPY / QQQ / IWM 是否同步
- **面板系统**：`Full` 与 `Mobile` 两种模式
- **Smart Alerts V2**：按等级触发，单根 K 线去重，跨 K 线允许严格升级

## v7.6 可靠性与自适应更新

- 只有实时真正发布提醒时才占用发送状态；加载历史 K 线不会提前消耗之后的实时提醒。
- 盘中触发并保留的标记会同步更新冷却和共振历史；强信号升级、背离冷却也使用已经接受的事件。
- 面板、背景区间和提醒方向按当前 K 线最高可见事件等级选择，同级买入优先。若盘中先后接受了双向事件，两个标记都保留。首次通知不会被撤回，同根 K 线后续升级也不会发第二条通知。
- `Auto / Fixed 252 / Custom` 回溯长度按当前图表 K 线计数；日内图的 `Fixed 252` 是 252 根 K 线，不是一年。
- SPY、QQQ、IWM 分别计算自适应区间、回溯长度和冷却。手动显示 QQQ 时不会再使用主图 SPY 的波动作为驱动。
- `Vol History` 的 `6 Months / 1 Year / 2 Years` 现在对应 **126 / 252 / 504 个已确认日线 RSI 样本**。这个日线长期基准与各市场当前图表周期的 RSI 波动结合，不再把所有日内选项截成同样的 1000 根 K 线。因此日内自适应结果会与 v7.5 有所不同。
- 数据短暂缺失时保留已接受的面板/区间状态，也不会重新解锁日线/确认数据模式的提醒；界面显示等待数据并暂时隐藏背景，只有数据有效的 HOLD 条件才清空内部状态。
- 统计预热期间，Auto 回溯使用可用的短期波动；自适应 RSI 区间不可用时回退到配置的固定区间。必要价格或评分因子缺失时，禁止新信号并显示 `WAIT DATA / 等待数据`。
- 同一广度源的 confirmed/developing 值合并为一个日线 tuple 请求；每个市场的已确认 252 日收盘高点、长期波动和样本计数也合并请求。尚未用 Pine Profiler 测量提速比例。
- 支持基于时间的日内周期和 **1D**。多日、周、月及 tick 图表会明确报错；固定 RSI 阈值必须严格排序；RSI Length 限制为 2–250，与历史缓冲区一致。

## 市场与数据源

- **跟踪市场**：`SPY`、`QQQ`、`IWM`
- **日线广度**：
  - SPY: `S5TW`, `S5FI`
  - QQQ: `NCTW`, `NCFI`
  - IWM: `R2TW`, `R2FI`
- **成交量广度**：
  - NYSE: `UVOL`, `DVOL`
  - NASDAQ: `UVOLQ`, `DVOLQ`
- **日内广度代理**：`ADD`；常规时段内对缺失值做 na 保护，单根 ADD 数据缺失时沿用上一有效值，评分不会瞬时跳水，盘后则冻结最后一个常规时段值
- **确认日线数据**：`f_secDailyLive()` 的 confirmed 返回值及 `f_secDaily()` 辅助函数都使用上一根已完全确认的日线值
- **日内实时警报模式**：`f_secDailyLive()` 在常规交易时段内使用 developing daily 数据，收盘后冻结广度/成交量快照
- **日内 session 处理**：SPY / QQQ / IWM / ADD 的日内请求会继承图表的 session 修饰符，扩展时段图表只会响应真实的盘后 bar

## 评分模型

脚本中的默认理论分数范围如下：

| 组件 | 买入最大分 | 卖出最小分 | 说明 |
|---|---:|---:|---|
| RSI | `+2` | `-2` | 固定或自适应阈值 |
| FI 广度 | `+3` | `-2` | 仅日线模式 |
| TW 广度 | `+1` | `-3` | 仅日线模式 |
| 成交量比 | `+2` | `-2` | `UVOL / DVOL` 或 `UVOLQ / DVOLQ` |
| ADD 广度 | `+3` | `-3` | 仅日内模式；此路径下日线 `TW / FI` 评分输入归零 |
| 回撤加分 | `+1 / +2 / +3` | `0` | 只影响买入侧 |

默认阈值计算结果：

- `maxBuyScore = 8`
- `maxSellScore = 9`
- `Buy Sensitivity = 50%` -> `BUY ZONE >= 4`
- 强买偏移 `+25%` -> `PANIC LOW >= 6`
- `Sell Sensitivity = 45%` -> `CAUTION <= -4`
- 强卖偏移 `+25%` -> `REDUCE <= -6`
- 灵敏度方向：`Buy/Sell Sensitivity` 百分比越低 = 阈值越低、信号越灵敏；百分比越高 = 越严格（输入提示已在 v7.5 修正为这一口径，计算公式本身没有变化）

模式调整：

- `Aggressive`：买入阈值更低，卖出阈值更宽松
- `Conservative`：买入阈值更高，卖出阈值更严格
- `Intraday`：额外再做 2 分灵敏度调整
- 最终弱买入阈值至少为 `+1`，弱风险阈值至多为 `-1`；强信号至少比同侧弱信号再严格 1 分。标准日线默认仍为 `4 / 6 / -4 / -6`。买入分可能含回撤加分或背离助推，因此双侧仍可能同时成立，由事件等级统一裁决。

## 信号说明

脚本当前使用的信号名称与图标如下：

| 类型 | 脚本触发条件 | 图标 | 标签 | 含义 |
|---|---|---|---|---|
| 强买 | `buyScore >= adjStrongBotThreshold` | `🚀` | `PANIC LOW` | 极端超卖，最强买入状态 |
| 买入 | `buyScore >= adjBotThreshold` | `📈` | `BUY ZONE` | 常规低吸区 |
| 中性 | 买卖阈值之间 | `⚪` | `HOLD` | 无明显优势 |
| 上涨中的风险 | 达到卖出阈值，但 `price > trend MA` 且趋势过滤开启 | `⭐` | `ELEVATED` | 高估但趋势未坏 |
| 风险 | 非上涨趋势下 `sellScore <= adjTopThreshold` | `⚡` | `CAUTION` | 止盈 / 风险控制区 |
| 强风险 | 非上涨趋势下 `sellScore <= adjStrongTopThreshold` | `⚠️` | `REDUCE` | 最强减仓状态 |
| 看多背离 | `divStrength < -threshold` 且 RSI 低于 `OS2` | `💎` | `DIVERGENCE` | 反转辅助 / 确认 |
| 看空背离 | `divStrength > threshold` 且 RSI 高于 `OB2` | `💎` | `DIVERGENCE` | 风险反转警告 |
| 买入共振 | `minAgree` 个市场在窗口期内进入买入侧（默认 2） | `🔥` | `RESONANCE` | 多市场看多确认 |
| 风险共振 | `minAgree` 个市场在窗口期内进入风险侧（默认 2） | `❄️` | `RESONANCE` | 多市场风险确认 |

几个关键点：

- `ELEVATED` 不是弱化版 `CAUTION`，而是卖出阈值已到、但趋势过滤阻止真正卖出信号时的正式显示状态。
- `ELEVATED` 与 `CAUTION` / `REDUCE` 一样受信号质量过滤约束：质量等级为 `C` 时不会显示或提醒 `ELEVATED`。
- 背离是独立叠加信号；启用 `Divergence Assist` 后，也可以推动边缘买入信号通过。
- 共振不是单一市场高分，而是跨市场同步。

## 过滤与增强机制

### 信号质量过滤

`f_signalQuality()` 的等级定义：

- `A`：3 个及以上因子同向
- `B`：2 个因子同向
- `C`：少于 2 个因子同向

开启后，只允许 `A/B` 级买卖信号触发；`ELEVATED` 也受同样的质量过滤约束。

### 回撤加分

`f_drawdownBonus()` 只增加买入侧分数：

- 回撤 `>= 5%`：`+1`
- 回撤 `>= 10%`：`+2`
- 回撤 `>= 20%`：`+3`

它影响买入判定和买入/中性面板分数。风险状态的主面板及风险提醒使用原始卖出分；DD 行把启用的加分明确标为买入侧，关闭回撤加分后不再显示加分注记。

### 背离助推

启用后，看多背离可以在分数还差 **1-2 分** 时提前推过买入阈值。

### 动态冷却

冷却期会根据波动率变化：

- 高波动 -> 缩短
- 正常波动 -> 保持
- 低波动 -> 拉长

只要基础冷却不是 0，脚本会保证最小冷却为 3 根 K 线。

## 面板说明

当前脚本有两种面板模式。

### Full 模式

代码中的真实布局：**7 行 x 1 列**

| 行 | 内容 |
|---:|---|
| 0 | 信号 + 分数 + 趋势，例如 `🚀 PANIC LOW +6.5↑` |
| 1 | 居中分数条 |
| 2 | RSI 分项 + 成交量分项 |
| 3 | 日线显示 `FI + TW`；日内显示 `ADD` 与实际已确认日线 RSI 历史覆盖，如 `Hist/历史:126/252D` |
| 4 | 趋势 + 背离 + 面板当前方向的因子质量（`B/买` 或 `S/卖`）；日线 `/4`、日内 `/3`。AGG 对平均同向因子数向下取整后评级，不显示隐藏背离事件 |
| 5 | 回撤 + 已启用的买入加分 + 过滤/数据状态，例如 `DD8% B/买+1` |
| 6 | 三市场原始因子状态 + 共振图标：灰色为数据不可用，红色为原始卖出分达阈值，其余情况买入分达阈值为绿、中性为黄；圆点不应用质量和趋势过滤 |

### Mobile 模式

代码中的真实布局：**2 行 x 1 列**

| 行 | 内容 |
|---:|---|
| 0 | 信号 + 分数 + 趋势 |
| 1 | 过滤状态 |

### 过滤状态含义

| 显示 | 脚本条件 | 含义 |
|---|---|---|
| `WAIT DATA / 等待数据` | 必要价格/评分数据缺失 | 禁止新信号 |
| `WARMUP / 预热` | 自适应统计尚未就绪 | 正在使用短期波动或固定 RSI 区间 |
| `👀` | 当前没有过滤阻塞 | 观望 |
| `✋ WAIT` | 分数达到买入区，但信号被过滤 | 分数够了，确认还不够 |
| `☕ HOLD` | 原始卖出评分（不含回撤加分）达到卖出阈值，但上升趋势阻止卖出 | 风险升高，但趋势未坏 |
| `🚫` | 下跌趋势中进入买入区、趋势过滤开启，且当前没有已绘制/激活的买入信号 | 熊市风格风险过滤 |

两个口径细节：

- `☕ HOLD` 以及 HOLD 区间 / 区间退出的判断都使用原始卖出评分（不含回撤加分），因此大幅回撤加分推高显示分数时，过滤状态不会与实际卖出阈值口径错位。
- `🚫` 只在没有任何已绘制/激活买入信号时显示，不会与图上的 `BUY ZONE` 标记互相矛盾。

### 如何一起看 `filterStatus` 与 `signalText`

`filterStatus` 和主信号行表达的是两层不同的信息：

- `filterStatus` 表示当前有没有被过滤器拦住。
- 在 `SPY / QQQ / IWM` 显示模式下，`signalText` 跟随已接受的图形事件；同根 K 线双侧冲突时取较高事件等级，同级买入优先。盘中已接受的标记不会因原始条件回落而撤回；`ELEVATED` 也进入风险背景区间。AGG 主标题显示 `RESONANCE / 共振`，提醒仍仅为 Lv3。
- `signalText` 表示当前真正的市场状态：`PANIC LOW`、`BUY ZONE`、`HOLD`、`ELEVATED`、`CAUTION`、`REDUCE`。

要把两者合起来看：

- `👀 + ⚪ HOLD`：没有过滤阻塞，但当前也还没有买入信号。这是一个干净的中性状态，不代表可以直接买入。
- `👀 + 📈 BUY ZONE`：已经进入买入区，而且没有过滤阻塞。这是标准的有效买入窗口。
- `👀 + 🚀 PANIC LOW`：已经进入更强的买入状态，而且没有过滤阻塞。

## Smart Alerts V2

脚本当前的警报等级如下：

| 等级 | 触发内容 |
|---:|---|
| `Lv1` | `BUY ZONE`、`CAUTION`、`ELEVATED` |
| `Lv2` | `DIVERGENCE` |
| `Lv3` | `RESONANCE`（主触发 + 共振升级，或 `AGG` 路径的纯共振） |
| `Lv4` | `PANIC LOW` 或 `REDUCE` |
| `Lv5` | `PANIC LOW + RESONANCE` 或 `REDUCE + RESONANCE` |

警报行为：

- 智能警报直接复用图上标识使用的 `Trig / Edge` 触发信号，不再直接根据原始实时状态发出提醒
- 智能警报跟随当前显示模式下实际可见的 K 线信号路径，避免提醒和图上标记、面板主信号脱节
- `Lv2 (DIVERGENCE)` 和 `Lv3 (RESONANCE)` 只作为当前可见主买入/风险触发的升级标签，不会再单独发出隐藏提醒
- 共振升级标签对所有显示路径生效：在 `SPY / QQQ / IWM` 上，若可见的主买入/风险触发与共振边沿出现在同一根 K 线，会发布 `Lv3`（主触发 + 共振）或 `Lv5`（强信号 + 共振，例如 `PANIC LOW + RESONANCE`）
- 智能警报会在最新实时 K 线首次出现可见触发等级的那个 tick 发布；之后的历史回填可能重塑更早的 K 线，但不会撤销或重放该提醒
- 实时 bar 上的图形信号会按整根 K 线锁存；盘中某个 tick 只要已经触发过买入/风险标记，这根 bar 收盘后仍保留对应标记，并和面板状态保持一致
- 同一根 K 线里，即使实时条件短暂消失后又回来，同级别或降级警报也不会重复发出
- 智能警报每根 K 线最多只发布一次；若同一个 tick 同时满足买入侧和风险侧，只发布等级更高的一侧
- 用 `varip` 防止同一根 K 线重复发低等级警报
- 已发布等级同样使用可抵抗 realtime rollback 的 `varip` 状态，因此不会在同一根实时 K 线上按同级别反复重发
- 在手动 `SPY / QQQ / IWM` 显示模式下，`AGG` 共振不会再单独走一条当前图上不可见的隐藏提醒路径；纯共振提醒只属于 `AGG(共振)` 显示路径，且 `AGG` 路径只会发布 `Lv3` 共振提醒（该路径没有强信号/背离状态）
- 在 `日内 + Live Alert Data` 模式下，同侧提醒会在整个常规交易时段内锁存，因此 `Lv1` 不会在当天盘中反复提醒
- Live 日内的同侧锁存按交易日日期检测重置：每个新交易日的第一根常规时段 K 线重新解锁提醒，纯 RTH 图表（不含盘前盘后）也能正常跨日重置；在当前时段内，同级重复和降级都会保持静默
- Live 日内仍然只允许跨后续 K 线的严格升级提醒（`Lv1 -> Lv3/4/5`）
- 跨 K 线会保留已发布等级；同一方向若维持在相同或更低等级，不会重复提醒
- 买入侧与风险侧分别去重
- `ELEVATED` 只会在首次进入或后续升级时提醒，不会每根 bar 都重复发
- 日内图在 `Live Alert Data` 开启时可用实时日线 developing 数据
- 日内图的智能警报只在常规交易时段触发；收盘后脚本仍会冻结广度快照，但既不会发布盘后提醒，也不会在盘后重置同侧锁存

## 已知限制

以下数据机制限制继续保留：

- **历史日内 K 线使用收盘后的日线广度值**：`f_secDailyLive()` 带 lookahead，历史日内 K 线拿到的是当日收盘后的最终广度/成交量值，而实时提醒使用的是盘中 developing 值。因此历史日内标记可能比实时实际触发的效果更好，历史标记不等于对实时行为的回测。
- **日线图的广度/成交量因子滞后 1 天**：日线图上这些因子来自日线请求中的上一根已确认值；`Live Alert Data` 选项只影响日内图，对日线图没有作用。
- **期货标的仅尽力识别**：`ES / NQ / RTY` 等期货代码的识别是 best-effort；常规时段限制与广度冻结逻辑按美股股票常规交易时段设计，未针对期货时段验证。

## 验证方式

本地行为回归使用 Python 标准库：

```sh
python3 -m unittest discover -s tests -v
```

检查覆盖部分实际源码函数、状态序列和源码连接契约，**不等于 Pine 编译器、TradingView 运行环境、性能测试或策略回测**。仍需在 TradingView 完成：

1. 将 `RSI+` 复制到 TradingView Pine Editor
2. 点击 `Add to Chart`
3. 在 `SPY`、`QQQ`、`IWM` 上检查表现
4. 检查 `Full` 和 `Mobile` 面板模式
5. 对照上面的信号、风险、背离、共振逻辑检查显示和警报
6. 在开启扩展时段的日内图上，确认常规收盘后不会再出现智能提醒
